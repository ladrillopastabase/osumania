Cómo activar la descarga de YouTube

Una página web no puede bajar audio de YouTube por sí sola. El ayudante es un programa pequeño que corre yt-dlp en tu computador y le pasa el audio a esta página.

  1. Instala Python 3 y, recomendado, Deno o Node (YouTube los exige).
  2. Descarga youtube.py.
  3. En una terminal: pip install "yt-dlp[default]" y luego python youtube.py. Déjala abierta.
  4. Vuelve aquí y pulsa . Si el navegador pregunta si la página puede acceder a dispositivos de tu red local, acepta.

Funciona en Chrome, Edge y Firefox (Safari no deja que una página segura hable con tu equipo). Si YouTube empieza a fallar, actualiza: pip install -U "yt-dlp[default]".

El audio no sale de tu equipo: el análisis y la generación se hacen en el navegador.
